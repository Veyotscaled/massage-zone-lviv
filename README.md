# Massage Zone Lviv

Український сайт масажного салону. Статичні сторінки, багатошаровий паралакс, власна 3D-композиція на Three.js, адаптивна навігація та запис через Instagram.

## GitHub Pages

Публікація з гілки `main`, каталог `/ (root)`. Збірка не потрібна. Всі локальні посилання відносні та працюють на адресі репозиторію GitHub Pages.

## Зміст

- `index.html` — головна, запити на масаж, порядок запису, відповіді та контакти.
- `studio.html` — знайомство з простором.
- `style.css` — адаптивне оформлення.
- `app.js` — навігація, діалоги, паралакс, курсор і переходи.
- `motion.css` — поява рядків, послідовне розкриття карток та переходи шторкою на виході й на вході.
- `scene.js` — інтерактивна 3D-композиція.
